# Wally Gen

Desktop UI that wraps the `mclovinbot` signup runner. Edits the config and
input lists in place, spawns `run.bat`, watches `dumps/` and the result
CSVs, and surfaces everything in a dark, monospace UI:

| Tab          | What it does                                                                   |
| ------------ | ------------------------------------------------------------------------------ |
| Tasks        | Paste emails + proxies, hit Start All. Live progress table per email.          |
| Settings     | Edit `.env` (IMAP / solver / engine groups). Save preserves comments + order.  |
| Output       | View `accounts.csv` and `accounts-failed.csv` with filter + sortable columns.  |
| Logs         | Live stdout/stderr from `run.bat` with line-level color coding.                |
| Email Filter | Subtract `accounts.csv` from a master list, optionally replace `emails.txt`.   |

## Stack

- **Tauri 2** + Rust shell (single ~20 MB `.exe` on Windows)
- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** for styling
- `notify` (Rust) for filesystem watching of `dumps/` and the CSVs

## Target folder

Wally Gen does not contain the signup runner — it drives an external folder
that holds:

```
run.bat
mclovinbot-engine.exe
px-solver.exe
profiles/             # solver fingerprint pool
etc/api-keys.json
emails.txt
proxies.txt
.env                  # IMAP creds, concurrency knobs, etc.
accounts.csv          # written by the engine
accounts-failed.csv
dumps/                # per-stab forensic JSON
```

Resolution order for that folder:

1. `WALLY_TARGET_DIR` environment variable, if set and contains `run.bat`.
2. The directory containing `wally-gen.exe` itself.
3. `C:\WalmartGen\me` (development fallback).

So the natural deployment is to drop `wally-gen.exe` + `WebView2Loader.dll`
into the runner folder and double-click.

## Build

Requires **Node 20+** and **Rust 1.77+** with the toolchain for your
platform.

```bash
npm install
npm run tauri dev     # development window, hot reload
npm run tauri -- build --no-bundle
```

The release exe lands at `src-tauri/target/release/wally-gen.exe`.

### Windows-GNU note

On `x86_64-pc-windows-gnu`, the mingw `ld.exe` hits *"export ordinal too
large"* if the lib crate exposes too many symbols. `src-tauri/Cargo.toml`
ships `crate-type = ["rlib"]` only (no `cdylib`/`staticlib`) to dodge that.
If you re-enable mobile targets, also switch to the MSVC toolchain.

On `x86_64-pc-windows-msvc`, no special handling needed.

### WebView2 runtime (end users)

The exe is dynamically linked against `WebView2Loader.dll`, which must sit
next to it. The release script copies it from
`src-tauri/target/release/build/webview2-com-sys-*/out/x64/`.

The end user's Windows must also have the WebView2 *runtime* installed
(Microsoft component, separate from the loader DLL). Windows 11 ships it
preinstalled; on Windows 10 it's installed by Edge / Office. If missing,
install from
<https://developer.microsoft.com/microsoft-edge/webview2/>.

## Icon

A placeholder violet diamond is generated by
`scripts/make-icon-source.ps1` (System.Drawing). To use a custom logo,
replace `src-tauri/icons/source.png` and regenerate the full icon set:

```bash
npx tauri icon src-tauri/icons/source.png
```

## Project layout

```
src/
  App.tsx                          # sidebar + paged shell
  components/                      # TitleBar, Sidebar, Card, StatusBar
  pages/
    Tasks.tsx                      # paste boxes + live progress table
    Settings.tsx                   # .env editor with IMAP host dropdown
    Output.tsx                     # sortable CSV viewer
    Logs.tsx                       # colored stdout/stderr stream
    EmailFilter.tsx                # subtract accounts.csv from emails.txt
  state/
    RunContext.tsx                 # shared run state across pages
    useRun.ts                      # event listeners + start/stop wiring
  lib/
    tauri.ts                       # invoke() wrappers
    transforms.ts                  # CSV → email:password (ported from multitool)
src-tauri/
  src/
    lib.rs                         # tauri builder, handlers
    paths.rs                       # target-dir resolution
    fsops.rs                       # .env round-trip + safe file IO
    run.rs                         # spawn run.bat, watch dumps/ + CSVs
    commands.rs                    # #[tauri::command] surface
  Cargo.toml
  tauri.conf.json
  capabilities/default.json
```

## Versioning

Bump in four spots when you cut a release:

- `package.json`
- `src-tauri/Cargo.toml`
- `src-tauri/tauri.conf.json`
- `src/components/TitleBar.tsx` (the `VERSION` constant)
